1. CLASS ==> PROPERTIES + FUNCTIONS + CONSTRUCTOR (OPTIONAL)
2. ENCAPSULATION ==> HIDING THE SENSITIVE PROPERTY BEING ACCESSED OUTSIDE THE CLASS ..EX...BALANCEAMOUNT //private modifier
3. INHERITANCE ==> ALLOWS THE CLASS TO RE-USE THE PARENT CLASS PROPERTIES + FUNCTIONS //parent--->child :
4. POLYMORPHISM==> MEHTOD OVERLOADING ==> A CLASS CAN HAVE MULTIPLE METHOD NAMES BUT WITH DIFFERENT PARAMETERS (IN LENGTH + DATATYPE) ==> 1, 2,3,4 
		   METHOD OVERRIDING ==> A METHOD WHOSE LOGIC NEEDS TO BE IMPLEMENTED ACCORDING TO THE CLASS WHOEVER WANT TO USE IT..  virtual : implementation
			EX..PUBLIC VIRTUAL VOID PRINT () ===> PUBLIC OVERRIDE VOID PRINT ()
5. ABSTRACTION==> PROVIDES THE BASE COMMON FUNCTIONALITY, PROPERTIES ..AND ACTS LIKE AN BASE CLASS.. AND THE CLASSES WHO WANTS TO USE THE BASE CLASS 		CAN BE TREATED AS CHILD CLASS .. EX..PUBLIC CLASS REGULARBANKACCOUNT : ABSTRACTBANKACCOUNT
			PUBLIC ABSTRACT VOID PRINT () ===> PUBLIC OVERRIDE VOID PRINT ()
6. INTERFACE==> ITS AN CONTRACT HAVING THE METHOD SIGNATURES..AND THOSE NEEDS TO IMPLEMENT WHOEVER WANTS TO USE THOSE FUNCTIONS..
			EX..PUBLIC INTERFACE IBANK==> VOID DEPOSIT() ===> SAVINGBANKACCUNT : IBANK==> VOID DEPOSIT(){"PRINT"}
